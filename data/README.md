# 数据来源说明（data/）

本目录为**竞赛主办方公开发布的题面材料**，仅用于复现本仓库的计算结果，**不在 MIT 许可范围内**
（版权归 2026 年高教社杯全国大学生数学建模竞赛组委会所有，详见 [`../NOTICE.md`](../NOTICE.md)）。

| 文件 | 说明 |
|---|---|
| `B题.pdf` | 2026 年高教社杯全国大学生数学建模竞赛 B 题题面（含附录 1–4） |
| `附件/附件1.docx` | 模拟器使用说明（机器狗行为规则、计时规则、模拟器操作指南） |
| `附件/附件2.docx` | 模拟器通信接口说明及编程指南（HTTP+JSON 协议、物理规则、示例程序） |
| `format2026.doc` | 全国大学生数学建模竞赛论文格式规范 |

## 与本仓库代码的关系

- **计时与规则**：附件 1/2 中可量化的规则（移动 5 m/s、检测 5 s、换频道 1 s、
  清除 3 s/5 s、近距阈值 5 m、清除半径 20 m、有效接收半径 1000–1500 m、定向源 ±90°）
  已固化在 [`../work/lib/sim.py`](../work/lib/sim.py) 中，并逐条对齐；
  `work/verify.py` 用附件 1 第 3 节的指令-计时示例做端到端回归（虚拟时刻 105 / 111 / 194 / 199）。
- **实机运行**：`work/official_robot.py` 按附件 2 的通信协议实现 `/enter`、`/measure`、`/clear`、`/exit`
  四条指令的完整调用流程，可直接用于官方模拟器的演练与正式测试。
- **不包含**：官方"无线电干扰源环境模拟器"程序本身（需参赛队号在线登录，由主办方网盘分发）。

## 删除本目录

本目录可安全删除：代码不读取其中的数据文件（规则已固化在源码中）。
删除后仍可完整复现 `work/` 下的全部演练统计与检验结果。
